# Olivia Skills

Olivia 的可复用创作规范。

## 第一个技能：稚拙风 PPT

[查看 SKILL.md](skills/naive-ppt/SKILL.md)

纯白底、大面积留白、橘红色 MS Paint 鼠标涂鸦。英文标题与中文说明，文案介于通俗和思辨之间。支持制作连续 HTML 演示，也支持把现有 PPT 或截图迁移到这套风格。

包含版式规范、文案示例、插画生成与转绘 prompt，以及 HTML 起稿模板。

> 使用 $naive-ppt，把这四页内容改成稚拙风连续 HTML。保留表格和交互逻辑，添加橘红色鼠标涂鸦。

仓库保存技能源码。要让工具自动调用，请将 `skills/naive-ppt` 安装到该工具支持的技能目录；仅上传 GitHub 不代表已安装到 ChatGPT。
