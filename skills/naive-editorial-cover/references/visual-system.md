# Visual system｜鼠标画出来的文学封面

## 视觉家族命名
**Naive Editorial Cover / 鼠标稚拙·文学封面**。与 naive-ppt 的“纯白 + 橘红 #E6532F + 16:9 PPT”不同，此封面走 **白底、黑线、蓝紫微量配色**，允许与暖白文学HTML拼接。

## 样稿成功的可见特征
“智力成为水电煤”封面：一小叠书、一个略歪的墙面插座、一根尚未接上的插头，主体集中画面左半到中部，右侧大面积没有绘制；厚黑轮廓与蓝紫色线带相对，质感像低技能鼠标拖笔而非漂亮矢量插画。

**不把书与插座设为固定标志。** 成功是“一个日常隐喻+一处未完成的关系”，不是固定物品。

## 默认视觉Token
| 类别 | 建议 |
| --- | --- |
| 画布 | 1080×460 横封（可按发布平台替换） |
| 底色 | #FFFFFF 或与文章纸面统一的 #FAF9F5 |
| 轮廓 | 近黑 #111111，线段不规则，粗约4–8px（以成稿1080px宽为例） |
| 唯一彩色 | 蓝紫 #4746C4 / #4B4FCC 相近范围，按真实样稿微调 |
| 配色面积 | 占图形很小一部分，通常低于全画面15% |
| 填色 | 纯色、不均匀边缘可保留；不使用渐变 |
| 质感 | 少量像素台阶、轻微重复描线、鼠标折线不平整 |
| 构图 | 左侧或偏中焦点；右/上方为呼吸空间；视平台安全裁切调整 |
| 物件数量 | 1–3种主物件；相互关联胜过堆满符号 |
| 文本 | 默认无文字，标题另由可编辑文字层添加 |

色值是从现有封面的视觉近似抽象而来，**不是设计软件吸色验收值**；用户提供新标准时优先新标准。

## 像MS Paint，而不是低分辨率失真
- 可以歪：书页、插头的角度，墙壁边界略抖。
- 不可以糊：真实图像边缘仍清楚；导出原尺寸PNG。
- 可以笨：不完美透视、几笔填色不满。
- 不可以脏：大片随机噪点、写实纸纹、JPEG伪影、AI幻觉细节。
- 可以略错位：对象关系仍成立，例如插头确实可以接到插座。
- 不可以精致：统一Bezier细曲线、发光电线、设计师矢量路径不属于此风格。

## 公众号适配
缩略图里主物件必须能辨识，图内不硬塞学术标题；必要时输出无文字封面和彩色背景开关两个版本，但不要让“为了适配裁切”破坏概念。做小尺寸预览检查，手机深浅模式也要检查边缘对比度。
