# Anti-patterns and QA｜视觉版 AI slop 防火墙

| 失败表现 | 为什么失败 | 可验证修复 |
| --- | --- | --- |
| 机器人头、DNA、发光芯片自动出现 | 把任何AI话题画成行业图库 | 从正文找具体动作/物件，完全去掉行业符号 |
| 玻璃光泽、镜面3D、金属线缆 | 视觉炫技吞掉手绘人文气息 | 黑色实线+白底+唯一蓝紫平涂 |
| 每条线都非常光滑、对称 | 不像鼠标画 | 调低曲线光滑度，少量不匀重描，保留清晰主体 |
| 故意降采样到看不清 | 把稚拙误解为坏画质 | 原尺寸PNG，清晰边缘，只有绘制动作低技巧 |
| 书、脑、灯泡、星星、闪电、网络十多个符号 | AI图标拼盘，中心不明 | 1–3个物件，一条可以口述的关系 |
| 复杂技术图谱/精细连线 | 错把封面当信息可视化 | 把精确内容移至正文图表 |
| 渐变背景、贴纸阴影、装饰性英文 | 套模板，和编辑感冲突 | 只留安静纸面，文字在排版层处理 |
| 统一使用橘红 | 与已存在的 naive-ppt 技能混淆 | 明确本封面为黑线蓝紫，除非用户指定例外 |
| 忽略1080×460裁切或缩略图 | 公众号上传后主体被裁断 | 导出前核对像素尺寸、缩略图、视觉安全区 |
| 向用户声称“在公众号已测试”但未测试 | 可复制页面不等于发布成功 | 说明HTML/图片哪些环节实际测试了 |

## 两轮验收
**第一轮，意义**：画了什么？两件物品如何发生关系？遮住文章标题，能不能在三秒内认出来？与文章的核心矛盾相连吗？

**第二轮，形式**：有真正可见的黑线/像素台阶/单色点缀吗？是否模糊失真？有没有脏纹理或莫名阴影？主体是否远离裁切危险边缘？缩成手机缩略图还清楚吗？

**成功经验的真正可复用处**：此次“插座没有接上”的线与历史叙事形成关系；删掉任何书籍上的装饰细节，概念仍成立。再做别的文章时，复用的是这种视觉减法，而不是同一张构图。
