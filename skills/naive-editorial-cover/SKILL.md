# Naive Editorial Cover｜鼠标稚拙·文学封面

**笨拙的是画法，不是概念。** 图像可以有不准的透视、颤抖的线条与不稳定的填色，但观念必须具体、可辨，不可出现随机堆砌物件的生成式垃圾视觉。

## 先定文章隐喻，再画图
1. 用一两句话理解文章的单一核心冲突。
2. 从正文找**一件可画的日常物品和一个关系动作**（例如接通/脱落、装进/漏出、遮挡/打开），形成一个画面，不把整篇论文符号化。
3. 出3个不超过一句话的构图点子，评估具体性与歧义；选一种绘制，非必要不向作者追加大量问题。
4. 封面图默认**不内嵌文字**；文章标题由公众号编辑器或配套HTML呈现。必要文字另建可编辑图层。

## 视觉定调
阅读 references/visual-system.md（色值、留白、尺寸和质量门槛）与 references/prompt-recipes.md（可复用Prompt）。

- 圆钝而不匀的黑线、明显的鼠标绘制路径，局部生硬折点、略微像素阶梯；主体仍一眼可辨。
- 白色/微暖白底为主；黑色结构线为主，**单一蓝紫色**局部填色或少量电线；不要自动套用 PPT 的橘红。
- 一幅图优先**1–3个物件**，用断开的接线/间隙/错位讲出微弱的戏剧性；至少留40%的安静空间。
- 绘画低技巧而非脏乱：没有阴影、高光、纸张污渍、玻璃质感、3D或渐变粒子。
- 图像像一张年轻编辑亲手画的“不够好”的图，不像标准化AI插画套装。

## 导出与交付
- 先问/确定目标平台；没有指定时，导出**微信图文横封1080×460**的可用PNG，并检查标题安全区。其他渠道按实际需求另出正方形/竖封。
- 避免把物件紧贴左右边缘或裁切；准备好不同平台的安全裁切空间，尤其中心附近的核心信息。
- 可附透明底单独素材，但主封面默认完整白色画布。
- 输出PNG原图+可编辑的概念/Prompt说明。图像生成不可用时只提供Prompt及明确说明，不能宣称已完成。
- 文案类型/文章题材不是画风的一部分；下篇文章**换隐喻、换物品，不复制书本插座**。

## 质量门槛
- [ ] 一眼看懂画了什么，第二眼能看到隐喻
- [ ] 真正低技巧：粗糙线条、平面、少色、轻像素感；没有贴图肌理或 AI gloss
- [ ] 留白比例足够，右侧/中部不被图形塞满
- [ ] 目标尺寸正确且裁切无误
- [ ] 没有假UI、乱码、乱字、莫名多出的手脚
- [ ] 视觉差并非质量差：没有模糊、压缩马赛克、不可辨认的构型
- [ ] 阅读 references/anti-patterns-and-qa.md 完成反AI slop审查

关联：文字使用 literary-inquiry-essay；PPT沿用独立 naive-ppt。三者可搭配，不能合并成一种万能风格。
