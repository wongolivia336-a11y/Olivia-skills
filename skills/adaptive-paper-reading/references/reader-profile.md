# Reader Profile v0.1 | 公开、安全、可修订

此文件只保存对阅读实践有用的抽象偏好；不是私密个人档案、诊断、完整生活简历或不变性格标签。来源：用户明确的论文精读诉求、这次 Desmet 讨论以及其仓库现有写作规范。若与当前明确指令冲突，以当前指令为准。

## 主题优先级（初始种子，不等于排除其他学科）
- 主方向：HCI / Human-AI Interaction、AI 与数据设计、交互设计、具身交互、智能体行为与用户体验。
- 相关交叉：情感化设计、设计研究方法、设计理论与哲学、数据可视化、AI 评价和社会技术议题。
- 阅读目的：理解经典模型的生成逻辑；能从作者的证据延伸出可被反驳、可实证的研究问题；有可能用于研究汇报、学术写作与设计实践。

## 讲解偏好（只在有对话证据时提升信心）
- 用中文完整解释，保留并正确定义关键英文术语和作者原表达；不要只作摘要。
- 喜欢从一个具体反例/交互场景进入抽象理论，然后回到原文查证。
- 希望主动发现概念之间的逻辑缺口和研究边界，不只接受正确答案。
- 喜欢问答式精读，但只问真正有价值的一个问题；如果用户说“直接讲”，停止过度提问。
- 希望方法、公式、实验与统计能够从零解释，不假装懂。
- 对 AI 的自主性、行动权限与用户价值的冲突保持敏感；仅作为当前研究议题观察，不当作永恒政治/伦理立场。
- 尽量避免空洞夸赞、堆砌概念、跳到“选题计划”而漏掉当前原文。

## 动态参数（建议起点）
- output_language: zh-CN
- retain_original_terms: true
- default_mode: close
- pace: one_concept_or_argument_per_round
- questions_per_turn: 1
- examples: user domain only when appropriate, clearly labeled constructed
- evidence_strength: explicit
- visual_first: when source contains models/figures
- user_agency: can_skip_questions_or_change_mode

## 调整原则
观察一次回答≠长期偏好。每次只更新一条明确、有证据、可撤销的候选规则，列明日期、触发对话、支持强度与反例；经用户许可方可更新此公开文件。不要把对某个案例的判断变成用户永久人格设定。
