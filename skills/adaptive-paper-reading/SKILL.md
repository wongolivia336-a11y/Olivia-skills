# Adaptive Paper Reading | 先读懂，再思考，再产生研究

本 Skill 是编排层，不是 PaperSpine、paper-deep-reader、paper-reading 或 literature-review 的复制品。仅在相关上游 Skill 已安装且当前宿主可调用时路由；否则使用本 Skill 内置的证据、对话与记录流程，明确告知未启用上游功能。

## 任务契约
优先以用户提供的原文、页图、图表和附录为权威。获取 DOI、版本、页码映射；区分原始文献的命题、作者引用的前人观点、作者实验结果、讲解者推论、AI/HCI 迁移与待检验研究假说。扫描版缺文字层时逐页读页图；不能因无法检索就假装看过。

默认**不要直接长篇摘要**。先给一屏研究地图：研究问题、对象/边界、主张、证据与方法路径、重要图表、关键限制；问用户希望从哪里进入，但若目标明确直接开始。每轮围绕一个真正的理解障碍或可争辩判断讲解，收尾只给一个高价值问题；允许用户跳读、纠错、要求直讲，不强制问答闯关。

## 路由与工作模式
读取 references/routing.md；四种主要模式：
- skim（快）：10 分钟判断文章贡献、质量、证据、相关性与是否精读。可以调用上游 paper-reading。
- close（精）：锚定原文页码，逐概念、图、机制与证据讲；适合上游 paper-deep-reader。
- compare（对读）：构建文献矩阵、争论、前提差异、可兼容程度；适合上游 literature-review 和必要的学术检索。
- research（转化）：从阅读问题到可检验假说、研究设计和写作计划；正式论文成稿可交给安装成功的 paper-spine。

PaperSpine5 的完整功能依赖独立官方套件，且目前为 alpha；不要将本仓库的编排器或任何安装说明描述为已经安装运行套件。若用户仅想精读，绝不强制启动完整论文写作管线。

## 逐轮精读协议
1. **定位**：给出章节/印刷页/PDF 页，列一个可验证的原文论点和此次讨论的问题。
2. **直觉 → 严格定义**：用真实或清楚标明“教学构造”的例子解释，再回到作者术语及相邻概念的区别。
3. **机制**：找出参与变量、关系、方向、假设；对于图表明确它显示什么、不能显示什么。不能把概念图当作定量因果证明。
4. **证据**：指出实验/文本/图表如何支撑论断，样本、材料、测量、分析和可替代解释。证据不足必须说。
5. **争论**：最有力的反例是什么？用户的观点比作者走得更远的部分在哪？
6. **迁移**：至少在适用时给一个 HCI/人机交互、智能体、具身交互、AI 情感化设计的迁移示例，明确“原研究不直接证明此延伸”。
7. **回合闭环**：复述用户真正的新洞察（不奉承），继续提出一个聚焦问题；用户说继续时直接进下一节。

输出应是可阅读的教学文本，不是对每个句子强行分表；只在图/论证比较会显著获益时用表或图。保留英文原术语与中文解释，必要时解释公式、统计和研究设计，不默认用户已懂。

## 个人化与可生长
阅读 references/reader-profile.md（通用公开偏好）和 references/learning-loop.md（记录、证据与更新规则）。在每轮根据理解状况调节节奏，而不是固化为某一种永恒学习人格。
- 用户观点不自动等于作者结论；纠错时将不同层次分开。
- 每次识别真实的偏好或理解障碍，只形成**候选**学习观察；用户同意后，才写入本地私有日志或提出公开 profile 变更。
- 本仓库为 public：只提交脱敏的方法、通用示例和用户明确许可公开的抽象偏好。不要保存带身份、隐私、原始 PDF、受访者材料、付费文献正文、密钥。
- 不许暗示 Skill 能后台监测聊天或自动更新 GitHub；更新需用户指令、可用写入工具和可审核的提交/PR。

## 阅读输出最低验收
- [ ] 文章身份、原文版本、页码映射交代清楚，扫描材料检查过页面
- [ ] 事实、转述、解释、延伸、假说有清楚界限
- [ ] 核心图表说明“如何读 → 支持哪条主张 → 不支持什么”
- [ ] 至少一个反例挑战作者或读者的解释；不偷换研究论域
- [ ] 用户有权结束提问模式，切换快速读、分段读、写作模式
- [ ] 用户的学习记录经许可、可修订、可回滚，并避免私密数据进入公共 GitHub
