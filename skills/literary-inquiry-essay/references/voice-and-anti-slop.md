# Voice & anti-slop｜文字编辑的禁忌与替代

本文件不是“AI检测器”，而是一份可供人工判断的病句与套路清单。任何规则都不能禁止作者自然使用某个句式。

## 反面案例 → 改写思路

| AI slop 反例 | 问题 | 编辑方向 |
| --- | --- | --- |
| “不是效率的问题，而是权力的问题。不是技术，而是社会。”连续出现 | 用对照句假装论证已经完成 | 写清中间机制、限定条件和证据 |
| “打开。调用。生成。我们被改变了。” | 把气口切碎，无法积累思想 | 将动作放回一个时间地点和因果关系里 |
| “这场伟大变革将重塑人类文明的底层逻辑” | 不可证伪、概念膨胀 | 指明影响的人、制度和可观察变化 |
| “某种深刻的、复杂的、幽微的张力” | 形容词重复，宾语缺席 | 写出两项具体事物怎样冲突 |
| “尼采说……马克思说……福柯说……” | 理论陈列 | 每段只保留支撑当前推理的一位思想家 |
| “当我们谈到X，我们究竟在谈什么？”反复出现 | 套壳式悬念 | 直接展示X造成的意外后果 |
| 每段以一行加粗金句收尾 | 读者的思考被不断打断 | 一节只保留极少必要的强调 |
| 第一人称“我突然想起/我恍然意识到”却无真实细节 | 虚构感与廉价顿悟 | 改成可核实的实际观察，或删掉‘我’ |
| 用单个调查数字论证整个人类命运 | 过度推断 | 报告样本、时期、指标及限制 |
| 结尾“未来已经到来，答案在每个人手中” | 扁平口号 | 回到开头意象，给出范围有限的判断 |

## 句子与段落的可操作参数
- 不设强制字数；中文思想随笔常可用**两到四个信息完整的中长句**形成一个段落。短句在高潮或转折处才显眼。
- 约两百字以上的长段要检查是否包含两套不同论证；拆分出于意义，不为短视频式节奏。
- 全文超过3次的同一模板表达需逐处复核；不以程序一键替换。
- 允许“不是……而是……”作为正常中文修辞，但连着多段出现就应重写推理。
- 读出声：若每段结尾都像口播金句，或者所有转折都用“然而”“其实”，就重新组织叙述逻辑。

## 成功示意（抽象化，不复制既有文章）
- 弱：“AI正在普惠所有人。它也制造了新不平等。这是一个时代悖论。”
- 强：“同样的入口可能向两个人开放，却仍然留下不同的使用条件：一个人有设备、训练和反复试错的时间，另一个人或许只能获得偶尔一次的回答。要讨论所谓普及，就不能只统计入口是否存在。”

## 最终人工校订三遍
1. **逻辑遍**：每段新增了什么？有没有跳过前提便写结论？
2. **语言遍**：删套话与伪文学性；保留作者自然的不规则节奏。
3. **伦理遍**：区分实录、假设、象征和引用；让具体的人保有复杂性。
