# Literary Inquiry Essay｜文史思辨·缓慢推进

此 Skill 是**一种写作类型**，不是固定的作者声音，也不是“写关于AI的文章”。必须从当前作者的真实材料、疑问和阅读兴趣出发，不挪用之前文章中的狄更斯、图书馆、水电煤或模型例子。

## 写作任务契约
在心中或工作记录里固定：本次主题；一句**可被反驳的中心判断**；读者需要跨越的一个认知差距；已有亲历材料；需要核查的事实与理论；文章目标字数、平台、是否同时制成HTML。

- **用户要直接写作、修改、交付**时，优先动手，不持续苏格拉底式追问。不替用户扩张成一个论文计划。
- 核心问题限定为一条主线；最多3个必要的次问题，均需服务主线。
- 作者经验是问题的入口与论证的责任位置，不要凭空捏造第一人称经历或具有时间地点的故事。
- 不把“人文”“哲学”误写为海量名词、悲观口号和定论。

## 文章架构：有线索的悬念，而非鸡汤反转
1. **可信的异常场景**：一个真实日期、人物、物件、制度小事或作者实际动作；前2–4段用细节把读者带进去，暂不宣布全部结论。
2. **埋下不协调感**：揭示场景中的悖论，写成清楚的问题而非空泛的“时代巨变”。
3. **概念沿着问题长出来**：一段原典/思想实验/研究，只解决此刻一个逻辑障碍；写清原论域与本文延伸的边界。
4. **论证压力测试**：至少有一段最强反例，承认技术的解放性、制度成本或既有历史；作者须因此修正一句自己的判断。
5. **在有限结论中回环**：回到开头的物件/动作/人物，前后意义发生变化；避免高喊“未来已来”或强行留一个问号。

章节数由论证需要决定，通常3–5节。不是每一节都必须英文副标题、引文或金句。阅读感的悬念来自信息顺序和认知延迟，不来自“你绝对想不到”。

## 语言
- 中长句与短句结合，但**默认以信息完整的中长句承载因果、让步、条件、历史关系**。不要每行一小句、每句单独一段。
- 每段通常围绕一个判断、一个场景推进或一次反驳。句式自然交错，允许不规则韵律。
- 删除连续使用的“不是X，而是Y”“首先其次最后”“换句话说”“本质上”“值得注意的是”“时代的洪流”“深刻变革”等公式。
- 形容词不代替证据；不要把“克制”“锋利”“幽微”“某种”当万能情绪词。
- 每段应有新的事实、限定、推理或经验增量。段首不要机械地发问，段末不要机械地产出加粗结论。
- 引文需标注真实来源；直引仅在核对原文及译法后使用，通常更适合简明转述。

## 理论与事实契约
正文中的人物、年代、引文、数据、思想实验分别有来源记录。原典优先，权威学术二手来源可辅助；公开研究须核对作者、年份、研究对象、方法与局限。不可将作者针对工业机器/正义理论/媒介写作的研究说成直接讨论当代生成式AI。

引证不等于堆砌。只保留**若删去就会让论证变弱**的理论，优先一处理论承担一个论证任务。阅读 references/fact-and-theory.md。

## 执行流程
题目与材料审视 → 一句话主线 → 场景与转折顺序 → 资料核查 → 完整初稿 → 反例压测 → 去AI味语言编辑 → 来源与事实审核 → 按交付格式排版。

- 先阅读 references/narrative-architecture.md 和 references/voice-and-anti-slop.md。
- 阅读 references/field-notes.md 获取此次合作的成功/失败复盘。
- 若需要公众号HTML，参考 references/wechat-editorial.md；正文先定稿再做页面装饰。
- 可选使用 scripts/lint_essay.py 进行**启发式**检查，输出仅为警示，不得机械改写。
- 封面如需稚拙风，另行调用 **naive-editorial-cover**；不要把封面配色、图形风格写进这个文风 Skill。

## 完成交付的最低标准
- [ ] 有一条可复述的主线，不因增加引用而失焦
- [ ] 开头和结尾之间有可追溯的意义变化
- [ ] 现实经历未编造；论文与数据均能核验
- [ ] 理论原论域与本文应用已区分；至少一个强反例得到公平处理
- [ ] 不存在密集公式化对照句和过多单句段落
- [ ] 若有HTML：内容可复制、视觉与正文分离、图片不丢失，真实渲染经过检查
- [ ] 没有冒称所有内容、按钮、图片和外链已经测试
