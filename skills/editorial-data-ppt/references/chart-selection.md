# 信息图谱：什么数据对应什么图

## 先检查统计单位

原始记录、去重后产品、一级类、二级维度命中次数、三级标签、受访者与设计场景是**不同的统计单位**。每页至少写清：“N是多少？n是什么？能否多选？缺失如何计？” 不知分母就不画精确比例。

## 决策树

| 用户要回答的问题 | 适合形式 | 数据前提 | 常见错误 |
| --- | --- | --- | --- |
| 五类各占整体多少？ | 一个主圆环＋并列数量/百分比 | 唯一主类别，Σn=N | 多选类别硬拆成100% |
| 五类各自包含什么？ | 五列分层索引／一级—二级—三级 | 已确认标签词表 | 只画比例不列详细信息 |
| 一类产品主要是什么设备？ | 单类完整横向条形图 | 同类各设备 n 可合计 | 把可用长尾归入“其他” |
| 高频副类有哪些？ | 独立 n/N 圆环或小比例条 | 每个标签可多选 | 三个圆环值硬凑为100% |
| 五类在五个分析维度上标注多少？ | 表格+准确数量+单元格小数据条 | 缺失编码记录完整 | 用彩虹热力图掩盖未标注 |
| 20产品如何指向10个场景？ | 多对多矩阵＋案例映射 | 案例编号、机制、场景证据 | 直接跳结论 |
| 多节点之间真实数量怎么流动？ | 桑基／流图 | 真实流量边与守恒关系 | 用随机粗细当装饰 |

## 圆环的两个根本不同语义

互斥整体份额：`share_i = category_i / N_total`，校验 `sum(category_i)=N_total`，单环中所有扇区合计100%。

**多选独立出现率**：`presence_tag = distinct_product_with_tag / products_in_class`。某产品可同时拥有多个标签；每个标签独立一个圆环或数据条，几个 presence 不相加。

任何情况下都显示 n/N，而不是单独写一个巨大的百分号。要注明未标注数量，不能把未编码当作不存在。

## 条形图标尺

横条可用两个不同标尺，但必须明确区分：
- 数量排序 `len=n/max(n_in_slide)`：比较同页设备数量，数值旁显示 n。
- 占本类比例 `len=n/N_class`：横条共同标尺是0—100%，显示 n 和百分比。
**不得用数量排序条，却宣称长度是该类百分比。**

每类独立一页时尽量呈现设备类型全量名单、准确 n、代表产品（真实而非虚构）和小结；字体不够大就增页，不随便藏资料。

## 标签词典 vs 标注率

三级词条列出只表示研究**分析词表**；真实案例是否被贴上这些词条需要单独统计。总案例数 (N)、至少标记一维的不同案例数 (N_t)、全未标记数 (N_u) 应满足 (N_t+N_u=N)。标注率不足时，标题应写“目前记录了哪些维度”，不能写“哪些类别天然更偏爱什么”。

## 制图自检

```js
const check = (n,N) => { if(!(N>0 && n>=0 && n<=N)) throw Error('无效分子/分母') }
const percent = (n,N) => { check(n,N); return (100*n/N).toFixed(1)+'%' };
const isExclusive = (counts,N) => counts.reduce((a,b)=>a+b,0)===N;
// 仅对互斥类别检查合计=100%；对多选标签不可进行此检查
```

推荐成熟库：[Apache ECharts](https://github.com/apache/echarts)、[Observable Plot](https://github.com/observablehq/plot)、[D3](https://github.com/d3/d3)、[Vega-Lite](https://github.com/vega/vega-lite)。具体项目已有可编辑图层时优先直接复用。
