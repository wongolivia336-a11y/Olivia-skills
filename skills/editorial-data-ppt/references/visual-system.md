# 视觉系统：小红书式编辑排版 × 既定蓝白研究风格

## 不变的根本原则

**简洁是组织，不是信息贫乏。** 保留复杂图表、准确数字和分类细节；视觉元素尽量少。优先复用用户已有且确定的版式；不擅自给背景换色、给图表添加卡片，或重画品牌角标。

对小红书策略／营销提案的借鉴限定为：信息层级、页面节奏、编辑式留白、数据图形样式、同一体系内图表多样性。原营销方案中的受保护图片、专有文案、品牌资产不可未经授权复制发布。

## 项目实践母版（可迁移，非永久品牌默认）

| 项目 | 研究汇报实践 | 重用规则 |
| --- | --- | --- |
| 画布 | 1920×1080，16:9 | 严格按既有源文件尺寸 |
| 底图 | 深色原始星空 | 仅从用户授权原文件复制素材；不要自己生成“差不多” |
| 品牌角标 | 原有 D&I 标志，右上角 | 不允许未经授权重新临摹 |
| 数据区 | 大面积不透明白色板 | 不用十余个半透明玻璃卡替代 |
| 主色 | 蓝、深蓝、白色 | 当前项目近似蓝 #347FB9、深字 #183E5D、数据浅蓝 #DDEAF3；严格复刻以 Figma 实测为准 |
| 渐变 | 默认不加 | 原素材本身带渐变可以保留 |
| 标题 | 52–64px | 中文 Noto Sans SC 或沿用原字体 |
| 一二级 | 28–36px / 24–30px | 层级区别靠字重和留白 |
| 数据行 | 20–26px | 优先可读；全部文字最小 18px |
| 版边距 | 约 80–100px | 相同页面家族同一坐标系统 |

## 图形语言

- 真圆必须 w=h，半径计算不能拉伸；圆环外圆和内圆同心。
- 线、数字、箭头有合理粗细；不允许“像一根头发的 SVG”。投影重点线通常 2–3px，分隔线 1.5px 左右。
- 使用稳定网格（常用间距 8/16/24/32/48px），同列标题、图例、数值基线严格对齐。
- 清单式产品分布：设备类／条形／准确数量／案例名称四栏，尽量用弱分隔线而非整行圆角框。
- 总览：左主环、右类别列表，数字较粗；二三级细节同页或紧接的索引页；“只有大环”不满足“粗中有细”。
- 分主题高频：每个一级类别一张，三个**独立**圆环，各自 n/N、维度来源和代表产品。
- 图标优先成熟统一 SVG（Lucide、Tabler、Heroicons）；同页图标同一来源和描边宽度。开放源码也需要核对具体许可证。

## 不属于通用规范的东西

星空底、学校 Logo、客户原始案例编号和完整产品名单仅属于相应项目，公共 Skill 不打包这些资产。不得因模仿小红书而移植未经授权的图片和提案内容。


## v1.1｜蓝白渐变的适用边界和人味

“无AI味”不是“禁止任何渐变”。允许已通过的**蓝色纵向柱顶实色、柱底渐隐**以及克制的蓝色标题带；它们不改变数据几何。禁止荧光绿、神秘光圈、赛博发光、随意配色的条形、与数据无关的透明浮层。

每页只保留1个主要统计板；有明确参考时可用左右两大卡。信息层级由标题、空白、弱分割线、真实数量和案例名称建立，而非重复套圆角矩形。项目已有同济D&I角标与星空底图应**原样复用已授权节点**，不能再手绘一个类似版本；迁移到其他项目则替换为该项目真实品牌系统。

当制作圆环/饼图的内容相关高亮时，原总图的扇区颜色、角度、相对比例和起始顺序必须全页共用；只有**被文字明确讨论**的一块可以径向外展。椭圆、过细SVG、不统一描边、图表尺寸随意、投影时看不清的文字都属于失败；优先复用可核许可证的Lucide、Tabler Icons或Heroicons。

参考图片中可模仿信息的布置节奏，但不能因为参考用绿便把已确定蓝白系统改绿；完整第三方图像、提案内容不能进入公开Skill。
