# 反面案例清单（按实际反馈沉淀）

| 被否定的做法 | 直接修正 |
| --- | --- |
| 每个信息点都用独立透明圆角卡包住，像 AI 生成后台 | 大块白色数据底板＋弱分隔线＋真实数据图 |
| 荧光绿、赛博蓝光晕、无意义渐变 | 既定深色底图＋蓝白配色；数据层用纯色 |
| SVG线细到看不清、箭头极细 | 定义线宽，投影检查，统一几何构造 |
| 想画正圆却做成椭圆或尺寸不统一 | width=height，弧的中心和半径通过数学计算 |
| 自己随手绘制“不专业图标” | 直接用 Lucide/Tabler/Heroicons 等许可明确的开源 SVG |
| 只学小红书封面的颜色和胶囊，没有学到内容组织 | 研究信息结构、横向索引、阅读顺序和图表选型 |
| 研究总览只有一张大饼图 | 旁边列一级名／数量／占比，下接二三级明细 |
| 五类设备拼成一页五个小圆环 | 改为各类独立的全量条形图，设备名＋数量＋例子 |
| 长尾“其他”很多，却不展示实际设备 | 有数据就展开，不能隐藏分类 |
| 多选标签塞到一张100%饼图 | 独立 n/N 比例圆环或横向比较条 |
| 统计单位混用：320原记录、241合并产品、标签命中数 | 每页显式标注分母和去重口径 |
| 未标注等同于不具备特征 | 单列未标注；不能得出不存在的结论 |
| 用户明确不想要热力图，仍不断加热力 | 使用简洁表格＋行内数值条 |
| 字太小、密集到投影读不清 | 拆页重排，正文不小于18px |
| “高价值多维认知赋能”之类 AI 口吻 | 用“谁、何时、做什么、怎样回应” |
| 用户说1:1或只增不删，仍覆盖重做 | 原有不动，在旁边增量创建 |
| 把整页截图导进Figma称为可编辑 | 每个数值、图形、标签做成独立层 |

一句检查法：**去掉所有装饰后，老师还能否看出研究对象、统计数字、分类依据、代表产品与推导关系？** 如果不能，问题是信息设计，不是光效不够。
